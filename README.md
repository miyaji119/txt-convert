# TXT 优化器与 EPUB 转换器

模块化 Python 脚本，用于优化 TXT 小说文件并转换为 EPUB 格式。提供 **Web 界面**（推荐）和命令行两种使用方式。

## 功能特性

### 🌐 Web 界面（v3.0）

- FastAPI + 浏览器，无需安装 tkinter，macOS/Windows/Linux 通用
- **现代化工具台 UI（v3.0）**：统一 App Shell、顶部状态栏、侧边栏导航与多标签页视觉体系；主要页面采用 Hero + Step 卡片结构，突出当前文件、章节数、输出状态和下一步操作
- **响应式布局优化**：小屏下侧边栏横向滚动，表单 / 编辑器双列区域自动折叠为单列；EPUB 编辑器章节列表 + 编辑区使用响应式网格
- **可访问性增强**：导航支持键盘 Enter / Space 切换，按钮 / 输入框 / Chip / 状态栏链接具备清晰 focus ring；图标按钮补充 `aria-label`
- **编辑器重建稳定性修复（v3.0）**：`/api/editor/build` 请求模型补齐 `chapter_title_align`，与主 EPUB 生成接口保持一致，避免使用章节标题对齐参数时触发模型字段缺失
- 深色 / 浅色主题切换，偏好持久化
- 实时日志流（SSE），关闭浏览器标签自动退出服务
- 文件选择自动提取书名/作者，显示「自动识别」标签
- Toast 通知、动画进度条、导航徽标
- **自定义章节识别规则**（章节规则 Tab）：添加/启用/禁用自定义正则，高于内置规则优先匹配
- **广告过滤规则**（广告规则 Tab）：可调整关键词列表与评分阈值
- **广告扫描 + 逐行确认处理**（广告规则 Tab 顶部）：扫描可疑行（≥0.85 红 / ≥0.70 橙），高置信行自动预选；支持全选/取消全选/仅选高置信快捷操作；**混合行截取模式**：正文+广告混合行显示绿色「截取」标签，保留正文、仅删除广告片段（红色删除线预览），纯广告行整行删除；确认后点击「处理选中」生成 `*_adcleaned.txt`；**跨行 URL 识别**：自动检测被换行截断的推广网址；**行首社交账号前缀检测**：识别 `{}微博Cc栗~{` 一类行首推广前缀并截除
- **乱码噪声扫描**（广告规则 Tab 02 区）：检测隐形水印字符（零宽字符/PUA 码位）、HTML 标签残留、控制字符等，逐行预览并选择清理，生成 `*_noisecleaned.txt`
- **语义乱码扫描**（广告规则 Tab 03 区）：检测夹在句中的水印短语（如「也不**揄系正利。**怎么回家」），红色高亮上下文展示，用户人工审查后选择清除，生成 `*_garblecleaned.txt`；启发式规则，存在一定误判率
- **EPUB 排版自定义**（生成 EPUB 标签页「排版样式」可折叠面板）：页面边距、行间距、首行缩进、自定义 CSS 文本框；**实时排版预览**：调整参数后即时渲染示例段落，无需重新生成 EPUB
- **章节拖拽排序**（生成 EPUB 及目录编辑 Tab 的章节列表）：直接拖动行调整章节顺序，拖放目标行高亮提示，自动重新编号；⬆/⬇ 精调按钮同时保留
- **EPUB 编辑器**（v2.8，独立 Tab）：加载已有 EPUB 或 TXT 文件，对章节进行增删改、合并、查找替换、元数据编辑，再重建为 EPUB
- **日志全屏**：底部日志栏点击 `⊞` 按钮可将日志面板全屏展开（`position:fixed; inset:0`），便于查看长流程输出；点击 `×` 或 `⊠` 收起；底部状态栏操作已统一为可访问的状态链接

### TXT 文件优化

- 自动检测文件编码（支持 UTF-8、GBK、GB2312 等）
- 标准化章节标题格式
- **广告内容过滤**（URL、下载引导、平台推广等）
- **行内广告截取**：检测并截除正文行末尾内嵌的广告片段（如「记住网址m.42zw.cc」），保留前半段正文；全角混淆域名（如 `ｍ．４２ｚｗ．ｃｃ`）先归一化再匹配；亦检测行首社交账号推广前缀（如 `{}微博Cc栗~{`）并截除
- **语义乱码扫描**（Web UI 03 区）：检测夹在正文句中的网站水印短语（如「也不揄系正利。怎么」），启发式规则 + 用户人工审查，定点清除不影响正文
- **独立行水印清理**（读者 ID、转载者署名）
- **多书合并检测**：相邻章节人名/地名完全不重叠时自动停止并提示
- 段落合并、去重

### EPUB 生成

- 自动解析章节结构、提取书名和作者
- **保留文案简介**作为独立章节（书名/作者/文案各行各自成段，正确换行）；文案简介内容自动写入 EPUB `DC:description` 元数据
- **章节标题前缀清理**：自动去除聚合站下载文件中章节标题携带的书名冗余前缀（如 `《仙逆》第一章 王林` → `第一章 王林`）及标题内重复章节号（如 `第一章第一章 缘起` → `第一章 缘起`）
- **目录分页与分卷嵌套**：章节数 > 20 时自动拆分为「目录」「目录（续1）」等多页；自动检测「第X卷」等分卷标题，EPUB NCX 目录生成卷→章两级嵌套结构
- **手动卷分配**：通过 `volume_map` 参数将任意章节指定到卷中
- **章节标题分行样式**（`split_plain` 分行·极简 / `split_ruled` 分行·细线）：编号与标题各占一行渲染，无标准编号前缀的章节（如纯标题"前世""遇见"）自动补「第N章」作为编号行；序章/楔子/尾声等特殊命名章节不自动补编号
- 支持本地封面 / 在线 URL / 自动搜索（晋江、豆瓣、微信读书、长佩、起点、Bing 六源）/ **自动生成**（5 种风格：留白·默认 / 装帧·典藏 / 现代·编辑 / 版框·古风 / 日常·治愈；风格选择面板 + 实时预览）
- **封面候选预览弹窗**（Web UI）：缩略图网格，来源标注，置信度色标
- **内嵌章节编辑**（Web UI 生成 EPUB 标签页）：修改标题/编号、**拖拽排序**或上下移动章节、删除章节，保存后自动更新转换路径
- **作者有话说独立样式**：自动拆分章节末尾「作者有话说/作者碎碎念/作者叨叨」等段落，渲染为带左侧暖色竖线的独立卡片（`.author-note`），视觉上与正文明显区分；EPUB 目录生成嵌套子条目
- **精排组件（Phase 1）**：自动检测正文中的系统公告/提示/通知块和引用块，渲染为独立视觉组件：
  - `【系统提示】内容` / `【系统公告】` 单独行 + 后续内容 → 蓝色左边框卡片（`.sys-box`）
  - `===系统公告===` 行内边框标题 → 卡片标题行
  - `═══` Unicode 边框包围的多行内容 → 带提取标题的卡片
  - `>` 前缀行 → 斜体引用块（`.quote-blk`）
- **样式预设引擎**：内置双引号/角括号/单引号对话规则，支持 inline span（`<span class="dlg-cn">` 等）和 block 整段 class 两种作用域；可通过 `/api/style/presets` API 自定义
- **脚注系统**：正文中 `{{注:内容}}` 标记自动转换为 EPUB footnote（`<aside epub:type="footnote">`）
- **头图处理**（需 Pillow）：为每章插入带边缘蒙版的头图（fade/cloud/mist/torn/rough 等多种效果），按章节轮换
- **字体子集化**（需 fontTools）：按全书字符集裁剪内嵌字体，将体积从 10MB+ 压缩到几百 KB；支持 body/title/dlg/toc 四个角色分别指定字体
- **插图页**：在指定章节后插入全版面图片页，支持标题注释
- **同名章节自动合并**：自动合并网络抓取断点导致的相邻重复章节，根据末尾标点智能选择拼接方式
- **扩展元数据**：description（简介）、publisher（出版社）、isbn、pubdate、language、tags
- **重新分章**（`/api/resplit`）：支持临时注入自定义正则预览分章结果，dry_run 模式不写文件

### EPUB 编辑器（v2.8）

基于有状态会话（内存 `_SESSION`）的 EPUB 编辑工作流：

1. **加载**（`POST /api/editor/load`）：读取 `.epub` 文件（解析回章节/元数据）或 `.txt` 文件（直接解析章节）
2. **编辑**：章节 CRUD（GET/PUT/DELETE）、合并章节、元数据更新、全文查找/替换
3. **构建**（`POST /api/editor/build`）：从当前会话状态重新生成 EPUB，支持所有排版参数
4. **持久化**：`POST /api/editor/save-session` 保存到 `~/.txt2epub/editor_session.json`

### 章节识别支持

| 格式 | 示例 |
| ------ | ------ |
| 标准格式 | `第1章 标题` / `第一章 标题` |
| 等号分隔 | `==第1章 标题==` |
| 数字序号 | `1、第一章 标题` |
| 特殊章节 | `楔子` / `番外` / `终章` / `简介` / `内容简介` |
| 无「第」前缀 | `一章 标题` / `12章 xxx` / `三章`（低优先级，标题可省略） |
| 分部 | `第一部 标题` |
| 上下分章 | `第三章（上）` / `第三章（下）xxx` |
| 英文格式 | `Chapter 1` |
| **自定义正则** | 用户在 Web UI 章节规则 Tab 中配置 |

识别逻辑自动过滤「作者有话说」区域内的伪章节行，不影响紧接其后的真实章节标题。

## 快速开始

**Web 界面（推荐）：**

```bash
cd txt-convert
python3 web_server.py
# 浏览器自动打开 http://127.0.0.1:8765
```

**命令行：**

```bash
# 生成 EPUB（输出到输入文件同目录）
python3 txt-convert/cli.py input.txt

# 指定书名和作者
python3 txt-convert/cli.py input.txt --title "书名" --author "作者"

# 直接输出到指定书库目录
python3 txt-convert/cli.py input.txt --output-dir ~/Books/epub-library

# 只生成优化后的 TXT，不生成 EPUB
python3 txt-convert/cli.py input.txt --txt-only
```

## Web UI 功能说明

**TXT → EPUB**：主流程采用 Hero + Step 卡片布局。选择任意 TXT 文件后自动识别书名/作者、分析章节目录，Hero 区实时显示当前文件、章节数和输出状态。可直接点击「🚀 一键生成 EPUB」（内部自动先清洗再生成），也可点击「🔧 仅清洗 TXT」只生成优化后的 `*_epub_ready.txt`（清洗完成后路径自动切换到输出文件）。封面选项包括无封面 / 本地图片 / 图片 URL / 自动搜索（含五源封面候选预览弹窗）/ **自动生成**（5 种 BookCrafter 风格，风格选择面板 + 实时 90×135px 预览图）。选择文件后自动分析章节，内嵌章节编辑区域（支持拖拽排序）。「排版样式」可折叠面板提供页面边距（窄/标准/宽/超宽）、行间距（1.5–2.2）、首行缩进（0/1/2/2.5em）选项及自定义 CSS 文本框；面板底部有**实时排版预览**，调参数即时更新样式效果。底部 sticky 操作区集中放置输出目录、广告过滤、仅清洗和一键生成按钮，长页面中始终便于操作。

**批量转换**：采用统一 Hero + Step 布局。选择文件夹后批量处理目录内 TXT 文件，Hero 徽章显示成功数 / 总数；最近目录以 Chip 形式展示。

**EPUB 编辑器（v2.8）**：独立 Tab，采用响应式双列编辑布局。加载任意 EPUB 或 TXT 文件进入编辑会话，对章节标题/正文进行修改（编辑中显示「未保存」标记，切换章节前有确认提示）、合并重复章节、删除章节、全文查找替换、修改元数据（书名/作者/简介等），编辑完成后一键重建为新 EPUB。重建时可指定完整输出路径或输出目录（`output_dir` 优先级低于完整路径）。会话可保存/恢复。

**章节规则**：添加自定义正则（group 1 = 章节号，group 2 = 标题），启用/禁用单条规则，优先级高于内置规则。规则持久化到 `~/.txt2epub/chapter_rules.json`。配置文件路径行统一支持 Finder 显示 / 默认编辑器打开，并补充无障碍标签。

**广告规则 / 广告扫描**：调整硬关键词、软关键词和匹配阈值，持久化到 `~/.txt2epub/adfilter_rules.json`。关键词以可删除 Chip 展示。广告规则标签页包含三个扫描区段：

- **01 扫描广告**：选择文件后点击「扫描」，以彩色得分表格展示可疑行；混合行（正文+广告片段）显示绿色「截取」徽标，应用时只删除广告尾部保留正文；纯广告行整行删除；高置信行（≥0.85）自动预选，支持全选/取消全选/仅选高置信；确认后点击「处理选中」生成 `*_adcleaned.txt`，toast 分别显示删除/截取行数。同时检测被换行截断的推广网址及行首社交账号推广前缀（`{}微博Cc栗~{` 等模式）。
- **02 扫描乱码噪声**：检测零宽字符、PUA 码位、HTML 标签残留、控制字符等隐形噪声，逐行预览清理效果（带类型徽标），选择后生成 `*_noisecleaned.txt`。
- **03 扫描语义乱码**：检测夹在句中的网站水印短语（如「也不揄系正利。怎么」），以红色【短语】+ 上下文展示，人工审查后选择清除，生成 `*_garblecleaned.txt`；属启发式规则，存在误判，需用户确认。

三个扫描路径均自动同步「生成 EPUB」Tab 当前文件，切换标签页无需重复填写。

**目录编辑**：独立加载 TXT 文件，查看、编辑、**拖拽**或上下移动重排章节，统计信息（章节数/总行数/总字数）；加载后自动显示**书籍简介**（第一章前的文案内容，可折叠展开），保存为 `*_edited.txt`。页面采用与主流程一致的 Step 入口和章节数状态徽章。加载章节时同步在「生成 EPUB」Tab 的内嵌章节区域显示简介卡片。
