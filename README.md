# TXT 优化器与 EPUB 转换器

模块化 Python 脚本，用于优化 TXT 小说文件并转换为 EPUB 格式。提供命令行（CLI）和图形界面（GUI）两种使用方式。

## 功能特性

### 🖥️ 双模式使用

- **图形界面模式**：现代化侧边栏导航，可视化操作，降低使用门槛
- **命令行模式**：批量处理、自动化脚本

### TXT 文件优化

- 自动检测文件编码（支持 UTF-8、GBK、GB2312 等）
- 标准化章节标题格式
- 智能去重、广告过滤、段落合并
- 支持多种章节格式识别

### EPUB 生成

- 自动解析章节结构、提取书名和作者
- 支持本地封面 / 在线 URL / 自动搜索（晋江、豆瓣等平台）
- 封面候选选择对话框：缩略图网格，置信度标注
- 保留文案/简介内容在第一章前

### 章节识别支持

| 格式 | 示例 |
| ------ | ------ |
| 标准格式 | `第1章 标题` / `第一章 标题` |
| 等号分隔 | `==第1章 标题==` |
| 数字序号 | `1、第一章 标题` |
| 特殊章节 | `楔子` / `番外` / `终章` |
| 英文格式 | `Chapter 1` |

## GUI 使用说明

### 导航栏

左侧深蓝色导航栏包含四个功能页和两个工具按钮：

| 项目 | 说明 |
| ------ | ------ |
| 📄 单文件转换 | 将单个 TXT 转为 EPUB-ready 格式 |
| 📁 批量转换 | 批量处理文件夹内所有 TXT 文件 |
| 📖 EPUB 生成 | 一键转换并生成 EPUB，含封面选择 |
| 📑 章节目录 | 查看并编辑章节列表，保存修改 |
| ⚙ 设置 | 配置默认输出目录和自定义正则规则 |
| 📋 日志 ▼ | 展开/折叠底部日志区 |

任务完成后，对应导航项右侧会短暂显示 `✓`（成功）或 `✗`（失败）徽标，批量转换显示成功文件数量（如 `5✓`）。

### 1. 单文件转换

**操作流程**：

1. 点击「浏览...」选择 TXT 文件，或从「最近:」下拉选择历史记录
2. 系统自动提取书名、作者（可手动修改）
3. 勾选「转换后显示章节目录」（可选）
4. 点击「▶ 开始转换」，按钮实时显示进度（`⏳ 转换中…`）
5. 完成后按钮闪烁 `✅ 完成`，点击「打开输出目录」查看结果

### 2. 批量转换

**操作流程**：

1. 点击「浏览...」选择文件夹，或从「最近:」下拉选择历史目录
2. 点击「▶ 开始批量转换」
3. 处理结果以表格形式展示（文件名、状态、章节数、大小）

### 3. EPUB 生成

**操作流程**：

1. 选择 TXT 文件（原始文件自动先转换，EPUB-ready 文件直接生成）
2. 输入书名和作者（可从文件内容自动提取）
3. 选择封面选项：
   - **无封面** — 跳过封面
   - **本地图片** — 选择 jpg/png/webp 文件
   - **图片 URL** — 填写在线图片地址
   - **自动搜索（推荐）** — 搜索后弹出缩略图选择对话框
4. 点击「🚀 一键转换并生成 EPUB」

**封面候选选择对话框**（自动搜索时）：

- 搜索晋江、豆瓣等多个来源，最多返回 9 个候选
- 网格展示缩略图（120×170），标注来源和置信度
- 置信度标签：≥80% 绿色 / ≥50% 橙色 / 其他灰色
- 点击选中后下载高清版继续生成；无 PIL 时降级为文字卡片

### 4. 章节目录

**操作流程**：

1. 选择 TXT 文件，点击「▶ 加载」
2. 在编辑工具栏修改章节号和标题，点击「✓ 应用」
3. 使用 ⬆ ⬇ 按钮调整章节顺序（自动重新编号）
4. 使用 🗑 删除按钮移除章节（正文内容一并移除）
5. 点击「💾 保存修改」，生成 `_edited.txt` 输出文件

## 命令行参数

```bash
python3 txt_optimizer.py [input] [-o output] [--rules]
```

| 参数 | 说明 |
| ------ | ------ |
| `input` | 输入 TXT 文件路径 |
| `-o, --output` | 输出文件路径（默认：原文件名 + `_优化版`） |
| `--rules` | 打印当前规则配置后退出 |

章节编号工具：

```bash
python3 chapter_numberer.py novel.txt [-o output.txt] [--start 1] [--preview]
```

## 工作流程

```text
原始 TXT 文件
      │
      ▼
┌─────────────────────────┐
│  txt_optimizer.py       │  清洗广告 / 规范章节 / 去重
│  生成 *_epub_ready.txt  │  连续编号
└─────────────────────────┘
      │
      ▼
┌─────────────────────────┐
│  epub.py                │  解析章节 → 生成 EPUB
│  （可附封面）            │
└─────────────────────────┘
      │
      ▼
    EPUB 文件
```

## 封面搜索来源

| 来源 | 方式 | 状态 |
| ------ | ------ | ------ |
| 晋江文学城 | JSON API → 详情页 | ✅ 可用 |
| 豆瓣读书 | `j/subject_suggest` JSON 接口 | ✅ 可用 |
| 长佩文学 | SPA 页面解析 | ⚠️ 骨架（反爬严格） |
| Bing 图片 | `mediaurl=` 正则提取 | ⚠️ 兜底备选 |

封面形状过滤（宽高比 0.5–0.95、最小 200×280），支持本地缓存。

- 平台字体自适应：macOS PingFang SC / Windows 微软雅黑 / Linux Noto Sans CJK

#### 性能优化（同期）

- `chapter.py`：`analyze_chapter_structure` 内层扫描改为 `bisect` 二分查找（O(n²) → O(n log n)）
- `txt_optimizer.py`：`list.pop(0)` 改为 `collections.deque`，`startswith(tuple)` 替代生成器
- `epub.py`：用 `html.escape()` 替代 5 次 `.replace()` 手动转义
- `chapter_numberer.py`：模块级预编译正则，避免循环内重复编译
