# TXT 优化器与 EPUB 转换器

模块化 Python 脚本，用于优化 TXT 小说文件并转换为 EPUB 格式。提供 **Web 界面**（推荐）和命令行两种使用方式。

## 功能特性

### 🌐 Web 界面（v2.6）

- FastAPI + 浏览器，无需安装 tkinter，macOS/Windows/Linux 通用
- 深色 / 浅色主题切换，偏好持久化
- 实时日志流（SSE），关闭浏览器标签自动退出服务
- 文件选择自动提取书名/作者，显示「自动识别」标签
- Toast 通知、动画进度条、导航徽标
- **自定义章节识别规则**（章节规则 Tab）：添加/启用/禁用自定义正则，高于内置规则优先匹配
- **广告过滤规则**（广告规则 Tab）：可调整关键词列表与评分阈值
- **广告扫描（预览模式）**（广告规则 Tab 顶部扫描面板）：扫描但不删除内容，以彩色得分表格展示可疑行（≥0.85 红 / ≥0.70 橙）
- **EPUB 排版自定义**（生成 EPUB 标签页「排版样式」可折叠面板）：页面边距（窄/标准/宽/超宽）、行间距（1.5–2.2）、首行缩进（0/1/2/2.5em）、自定义 CSS 文本框（追加到内置样式末尾，可写 `span.dlg-cn { color: #4a6fa5; }` 等）

### 🖥️ 桌面 GUI（v2.1）

- CustomTkinter 现代化侧边栏导航，可视化操作
- 命令行模式：批量处理、自动化脚本

### TXT 文件优化

- 自动检测文件编码（支持 UTF-8、GBK、GB2312 等）
- 标准化章节标题格式
- **广告内容过滤**（URL、下载引导、平台推广等）
- **独立行水印清理**（读者 ID、转载者署名）
- **多书合并检测**：相邻章节人名/地名完全不重叠时自动停止并提示
- 段落合并、去重

### EPUB 生成

- 自动解析章节结构、提取书名和作者
- **保留文案简介**作为独立章节
- **目录分页与分卷嵌套**：章节数 > 20 时自动拆分为「目录」「目录（续1）」等多页；自动检测「第X卷」等分卷标题，EPUB NCX 目录生成卷→章两级嵌套结构
- 支持本地封面 / 在线 URL / 自动搜索（晋江、豆瓣等平台）
- **封面候选预览弹窗**（Web UI）：缩略图网格，来源标注，置信度色标
- **内嵌章节编辑**（Web UI 生成 EPUB 标签页）：修改标题/编号、调整顺序、删除章节，保存后自动更新转换路径
- **作者有话要说子章节**：章节末尾如含「作者有话说/作者有话要说」段落，自动在 EPUB 目录中生成嵌套子条目
- **`*` 场景分隔符**：单独的 `*` / `＊` 行作为场景分隔保留，不与下一段合并
- **对话引号 span 标记**：正文中 `"..."` 包成 `<span class="dlg-cn">`，`「」` / `『』` 包成 `<span class="dlg-sq">`，供自定义 CSS 使用
- **同名章节自动合并**：自动合并网络抓取断点导致的相邻重复章节，根据末尾标点智能选择拼接方式
- **扩展元数据**：支持 `description`（简介）和 `publisher`（出版社）字段
- **排版参数化**：页面边距、行间距、首行缩进均可在 Web UI 或 API 中配置；自定义 CSS 文本框追加到内置样式末尾

### 章节识别支持

| 格式 | 示例 |
| ------ | ------ |
| 标准格式 | `第1章 标题` / `第一章 标题` |
| 等号分隔 | `==第1章 标题==` |
| 数字序号 | `1、第一章 标题` |
| 特殊章节 | `楔子` / `番外` / `终章` |
| 英文格式 | `Chapter 1` |
| **自定义正则** | 用户在 Web UI 章节规则 Tab 中配置 |

## 安装依赖

```bash
pip install -r txt-convert/requirements.txt
```

主要依赖：`fastapi`、`uvicorn`、`ebooklib`、`chardet`、`requests`、`Pillow`。

## 快速开始

**Web 界面（推荐）：**

```bash
cd txt-convert
uvicorn web_server:app --port 8765 --reload
# 浏览器访问 http://localhost:8765
```

**命令行：**

```bash
# 生成 EPUB
python3 txt-convert/epub.py input.txt

# 优化 TXT
python3 txt-convert/txt_optimizer.py input.txt
```

## Web UI 功能说明

**单文件转换**：选择 TXT 文件后自动识别书名/作者（字段旁显示「自动识别」标签），点击「▶ 开始转换」。

**批量转换**：选择文件夹，批量处理所有 TXT 文件，结果以表格展示（文件名/状态/章节数/大小）。

**生成 EPUB**：封面选项包括无封面 / 本地图片 / 图片 URL / 自动搜索（含封面候选预览弹窗）。选择文件后自动分析章节，内嵌**章节编辑**区域——可修改章节标题/编号、上移/下移、删除章节，保存为新文件后自动切换生成路径。「排版样式」可折叠面板提供页面边距（窄/标准/宽/超宽）、行间距（1.5–2.2）、首行缩进（0/1/2/2.5em）选项及自定义 CSS 文本框（追加到内置样式末尾）。生成的 EPUB 结构：文案简介 → 目录页（章节数 > 20 时自动分页）→ 各章节正文（含「作者有话要说」嵌套子节）。分卷作品在 NCX 目录中自动生成卷→章两级嵌套结构。

**章节规则**：添加自定义正则（group 1 = 章节号，group 2 = 标题），启用/禁用单条规则，优先级高于内置规则。规则持久化到 `~/.txt2epub/chapter_rules.json`。

**广告规则**：调整硬关键词、软关键词和匹配阈值，持久化到 `~/.txt2epub/adfilter_rules.json`。标签页顶部「扫描广告（预览，不删除）」面板：选择文件后点击「扫描」，以彩色得分表格展示可疑行（≥0.85 红 / ≥0.70 橙）。

**目录编辑**：独立加载 TXT 文件，查看、编辑、重排章节，统计信息（章节数/总行数/总字数），保存为 `*_edited.txt`。
